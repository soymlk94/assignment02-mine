# Assignment 02 - Transforms

This assignment looks at using transforms to robustness test our models in PyTorch.

Read and follow the directions in the assignment folder to complete the assignment. Follow the instructions from the [assignments tutorial](https://github.com/ruc-practical-ai-fall-2026/tutorials/blob/main/05-assignments.md) to submit the assignment.

## Installation

Run `uv sync`, then select the project's `.venv` Python environment as the notebook kernel.

To add a dependency, for example `pandas`, run `uv add pandas`.
